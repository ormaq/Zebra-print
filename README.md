# Zebra Print Tools

Small tools for working with ZPL labels.

## Projects

- `zpl-image-converter` converts ZPL files or bytes into images locally.
- `zpl-capture-proxy` listens for raw ZPL jobs, saves them, renders PNG copies, and can optionally print or forward them.

The proxy depends on the converter. The converter is the reusable library.
